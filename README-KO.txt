무료 공개 방법 (GitHub Pages)
1. https://github.com 에서 무료 계정을 만듭니다.
2. New repository를 누릅니다.
3. Repository name에 indonesia-travel 을 입력합니다.
4. Public을 선택하고 Create repository를 누릅니다.
5. Add file > Upload files를 선택합니다.
6. 이 ZIP의 압축을 푼 뒤 모든 파일을 업로드하고 Commit changes를 누릅니다.
7. Settings > Pages로 이동합니다.
8. Build and deployment의 Source를 Deploy from a branch로 선택합니다.
9. Branch: main / folder: /(root)를 선택하고 Save를 누릅니다.
10. 몇 분 후 https://사용자이름.github.io/indonesia-travel/ 주소로 사이트가 공개됩니다.
